프로젝트 매니저 개인정보처리방침

Android 스토어판(com.winsh.projectmanager.store) · 시행일 2026-10-03 · 개발자 Winsh

1. 기본 저장 방식

처음에는 이 기기에만 저장하며, 회원가입이나 동기화 연결 없이 프로젝트·일정·할 일·업무보고·회의록·문서·파일을 사용할 수 있습니다. 스토어판에는 개발자의 동기화 서버 주소나 계정이 기본으로 지정되어 있지 않습니다.

2. 처리하는 정보와 목적

정보목적 및 선택
프로젝트, 업무보고, 일정, 회의록, 문서와 첨부파일사용자가 작성한 내용을 기기에 보관하고 출력합니다. 연결한 저장소에 동기화할 수 있습니다.
위치 및 출입 이벤트출장 자동기록을 켠 경우 등록한 장소의 좌표와 진입·체류·이탈 시각, 위치 정확도를 저장하여 출장일과 활동비를 계산합니다.
사진 및 카메라 결과사용자가 선택하거나 촬영한 사진을 명함·프로젝트 파일 등에 첨부합니다. 사진 라이브러리 전체를 수집하지 않습니다.
선택한 연락처의 이름·전화번호·이메일시스템 연락처 선택 화면에서 사용자가 고른 연락처를 담당자로 입력합니다. 주소록 전체 읽기 권한을 요청하지 않습니다.
동기화 계정 정보 및 인증 정보사용자가 선택한 Google Drive, MYBOX, WebDAV 또는 자체 서버에 로그인하고 동기화합니다. 인증 정보는 Android 기기 보안 기능으로 보호합니다.

3. 백그라운드 위치

프로젝트 매니저는 앱이 닫혀 있거나 사용 중이 아닐 때도 위치 데이터를 수집하여, 등록한 현장·숙소의 출입을 감지하고 출장일과 활동비를 자동으로 기록합니다. 이 기능은 기본적으로 꺼져 있습니다. 사용자가 안내에 동의하고 정확한 위치와 백그라운드 위치 권한을 허용할 때만 활성화합니다.

이동 경로와 연속 GPS 좌표는 기록하지 않습니다. 등록한 장소의 출입 이벤트만 기록합니다. 권한을 거부해도 다른 작성·관리 기능은 사용할 수 있습니다. 출장·장소 → 감지 설정 → 이 폰 자동기록 중지에서 중지하거나 Android 앱 설정에서 권한을 철회할 수 있습니다.

4. 동기화 및 외부 서비스

업무 자료와 출입 이벤트는 사용자가 동기화를 연결한 경우에만 선택한 저장소로 전송됩니다. 파일 내용 동기화는 별도 선택이며 기본 꺼짐입니다. 개발자 서버로 업무 자료를 자동 전송하지 않습니다. 사용자가 자체 서버를 선택하면 직접 입력한 서버 운영자의 정책이 적용됩니다. 전송은 HTTPS를 사용합니다.

지도 검색을 이용하면 검색어·지도 위치와 네트워크 접속 정보가 지도·검색 제공자(카카오, OpenStreetMap, Photon 등)에게 전달될 수 있습니다. Google 계정 연결 및 위치 감지는 Google Play 서비스를 이용합니다.

로컬 AI 요약은 지원 기기에서 실행됩니다. 모델 준비를 위해 다운로드가 필요할 수 있습니다. Google ML Kit SDK는 진단·사용량 분석을 위해 기기·앱 정보, 기기 또는 설치 식별자, 성능·오류 정보, 기능 이벤트, 입력·출력의 크기와 설정 언어 등의 정보를 HTTPS로 Google에 전송할 수 있습니다. 이는 업무보고 원문을 개발자 서버로 전송하는 기능이 아닙니다. Google SDK 데이터 처리 안내도 확인할 수 있습니다.

스토어판은 장소 등록 지도 화면으로 이동할 때 Google AdMob 전면 광고를 표시할 수 있습니다. 하루 최대 1회이며 광고가 준비되지 않으면 지도는 바로 열립니다. 보고서 작성·저장, 동기화, 자동 출입 감지에는 광고를 표시하지 않습니다.

Google Mobile Ads SDK는 광고 제공·측정·부정 이용 방지를 위해 IP 주소(대략적인 위치 추정에 사용 가능), 광고 식별자·앱 세트 ID 등 기기 또는 계정 식별자, 광고·앱 상호작용, 성능·오류 등의 진단 정보를 수집하고 Google과 공유할 수 있습니다. 등록한 현장 좌표, 출입 이력, 연락처, 업무보고 원문을 광고 요청에 추가하지 않습니다. 전송은 TLS로 암호화합니다. 필요한 지역에서는 Google 동의 화면을 표시하며, 변경이 필요한 경우 설정의 ‘광고 개인정보 선택 변경’에서 선택을 바꿀 수 있습니다. 광고 식별자는 Android 설정에서 재설정·삭제할 수 있습니다. 광고 SDK 데이터 처리 안내와 Google 개인정보처리방침를 참고하세요.

사용자가 파일을 공유하거나 이메일 앱으로 보내면 선택한 앱 및 수신자의 정책이 적용됩니다.

5. 보관·삭제와 사용자 권리

기기 자료는 사용자가 삭제할 때까지 보관합니다. 데이터 관리에서 개별 기록과 휴지통을 관리할 수 있습니다. 스토어판의 데이터 관리 → 모든 기기 데이터 삭제는 해당 스토어 앱의 자료·사진·파일·설정을 삭제하며 앱을 초기화합니다. 별도 설치한 개인 배포판의 자료에는 적용되지 않습니다.

기기 삭제는 원격 저장소 사본을 지우지 않습니다. 원격 사본은 선택한 서비스에서 앱 저장 공간 또는 프로젝트 매니저 동기화 폴더를 삭제하고, 필요하면 서비스의 휴지통도 비우세요. Google 연결 권한은 Google 계정의 연결된 앱 설정에서 철회할 수 있습니다. 자체 서버의 계정 삭제는 해당 서버 운영자에게 요청하세요. 이 앱은 개발자 운영 계정을 새로 만들지 않습니다.

삭제 전 필요한 자료를 내보내거나 백업하세요. 백업·공유 파일은 사용자가 직접 삭제해야 합니다.
