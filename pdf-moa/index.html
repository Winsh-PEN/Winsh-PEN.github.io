PDF 모아 사용 안내

PDF 합치기, 순서 변경, 회전, 나눠 저장과 글자·사진 편집을 하는 한국어 PC 프로그램입니다. 파일은 PC 안에서만 처리합니다. 현재 테스트판(1.3.0-rc1, 코드서명 없음)입니다.

1시작하기

  1. 배포 ZIP을 내려받아 압축을 풀고 PDF-Moa.exe를 실행합니다. Python 등 별도 설치는 필요 없습니다.
  2. 코드서명이 없는 테스트판이라 처음 실행할 때 Windows 보호 화면이 나올 수 있습니다. 추가 정보 → 실행을 누르세요.
  3. PDF를 창으로 끌어 놓거나 Ctrl+O로 추가합니다.
  • 인터넷 업로드, 계정, 사용 분석 전송 기능은 없습니다. 모든 파일은 PC 안에서만 처리합니다.
  • 마지막으로 쓴 폴더와 창 크기만 %APPDATA%\PDF-Moa\settings.json에 기억합니다. 문서 내용은 저장하지 않습니다.

2합치기와 순서 변경

  • 목록에서 페이지를 선택하고 ↑/↓ 키로 미리보기를 넘깁니다. 드래그나 위/아래 버튼으로 순서를 바꿉니다.
  • PDF를 목록 위로 끌어 오면 파란 선으로 들어갈 자리를 보여 주고 그 자리에 끼워 넣습니다. 목록 밖에 놓으면 끝에 추가합니다.
  • 여러 파일을 한 번에 추가하면 파일 이름순(1, 2, 10…)으로 들어갑니다.
  • 목록에는 페이지 썸네일이 표시되고(목록 위 작게/크게로 크기 선택), 편집한 페이지에는 편집됨이 붙습니다.
  • 목록에서 오른쪽 클릭하면 맨 위/아래로, 왼쪽·180° 회전, 복제, 빈 페이지 넣기, 선택 뒤에 PDF 끼워 넣기 등을 쓸 수 있습니다.

3저장과 나눠 저장

  • Ctrl+S로 전체를 합쳐 저장합니다. 저장 이름은 첫 원본 이름을 따라 ○○_합침.pdf, ○○_선택.pdf로 제안합니다.
  • 목록에 있는 원본 파일은 어떤 이름으로도 덮어쓰지 않습니다.
  • 나눠서 저장은 한 쪽씩, N쪽씩, 범위별(목록 번호, 예: 1-3, 4-10) 중에서 고릅니다. 고른 폴더 안에 PDF_분리_날짜_시간 폴더를 만들고 001_원본이름_p1-2.pdf처럼 저장합니다.
  • 아래쪽 파일별 책갈피를 켜면 원본 파일이 시작되는 쪽마다 파일 이름으로 책갈피(목차)를 만듭니다. 원본 PDF에 있던 책갈피는 옮겨지지 않습니다.
  • 암호 PDF는 틀리면 최대 3번까지 다시 묻습니다. 출력에는 원본 암호가 자동 적용되지 않습니다.
  • 저장하지 않은 목록이 있으면 종료 전에 확인합니다.

4글자와 사진 편집

  1. 편집할 페이지 하나를 선택하고 글자·사진 편집(Ctrl+E 또는 더블클릭)을 누릅니다. 빈 페이지에도 글자와 사진을 넣을 수 있습니다.
  2. 글자 교체, 글자 추가, 사진 추가, 글자 지우기 중 하나를 고릅니다.
  3. 페이지 위에서 영역을 드래그합니다. 글자 가운데가 영역 안에 들어간 글자만 선택되고 파란색으로 표시됩니다.
  4. 새 글자와 크기·색상 또는 사진을 지정합니다. 입력 창 오른쪽에 실제 PDF 결과가 실시간으로 표시됩니다. 사진은 비율을 유지해 영역 가운데에 배치됩니다.
  5. 넣은 글자·사진은 옮기기에서 끌어 옮기고, 오른쪽 아래 모서리를 끌어 크기를 바꾸고, 두 번 클릭해 고칩니다. 오른쪽 클릭으로 그 항목만 지울 수 있습니다.
  6. 미리보기를 확인하고 변경 적용을 누른 뒤 메인 창에서 PDF를 저장합니다.
  • 글자 입력 창에서는 Enter가 줄바꿈, Ctrl+Enter가 적용, Esc가 취소입니다. 편집 창은 Ctrl+휠로 확대·축소합니다.
  • 교체와 지우기는 흰색으로 덮는 방식이 아니라 선택한 글자를 실제로 삭제합니다. 원래 글자의 시작점과 줄 기준선은 유지합니다.
  • 원래 줄 수보다 줄이 많거나 영역 너비를 넘으면 적용하지 않습니다. 영역을 넓히거나 글자 크기를 줄이세요.
  • 수평·90도 방향을 지원하며, 비스듬한 글자는 위치 보존을 위해 교체를 막습니다.
  • 휴대폰 사진은 찍은 방향대로 세워서 넣고, WebP 사진도 넣을 수 있습니다.
  • 편집 내용은 저장 전까지 메모리에만 있습니다. 종료 전에 저장하세요. 원본 파일은 변경하지 않습니다.

5글꼴

  • 선택한 PDF 글꼴을 PC에 설치된 글꼴과 정확한 이름으로 비교해 자동 선택합니다. 혼합 글꼴이나 불확실한 이름은 자동 확정하지 않습니다.
  • 일치하지 않으면 설치 글꼴을 검색해 고르거나 TTF/OTF/TTC/OTC 파일을 추가하세요. 기본 한글 글꼴(Droid Sans Fallback)도 고를 수 있습니다.
  • 글꼴 파일은 사용자 PC에서만 읽으며 시스템 설치·업로드·프로그램 동봉을 하지 않습니다.
  • 글꼴의 OS/2 fsType에 따라 포함 금지·보기/인쇄 전용 등 제한이 있는 글꼴은 막습니다. 이는 기술적 검사일 뿐이며 상업적 이용 등 모든 이용조건을 판정하지는 않습니다.
  • 원래 글꼴을 찾더라도 자간·줄바꿈·문서 서식까지 완벽히 재현하지는 않습니다.

6단축키

단축키 동작
Ctrl+O PDF 추가
Ctrl+S 전체 합쳐서 저장
Ctrl+Z / Ctrl+Y 실행 취소 / 다시 실행
Ctrl+A 전체 선택 (목록에서)
Delete 선택 페이지 빼기 (목록에서)
Alt+↑ / Alt+↓ 선택 페이지 위/아래로 이동
Alt+Home / Alt+End 선택 페이지 맨 위/맨 아래로
Home / End 처음/끝 페이지 선택
Ctrl+R / Ctrl+Shift+R 오른쪽/왼쪽으로 90° 회전
Ctrl+D 선택 페이지 복제
Ctrl+E 또는 더블클릭 글자·사진 편집
Shift+F10 또는 메뉴 키 오른쪽 클릭 메뉴
Enter (순서 번호 입력란) 범위 선택 (1-3, 5 또는 1~3)

7지원하지 않는 것

  • 이미지로 스캔된 문서의 글자 교체와 OCR
  • 복잡한 양식, 전자서명, 태그, 메타데이터 등을 포함한 문서 전체의 민감정보 제거
  • 정보가 없는 글꼴과 가변 글꼴

8라이선스

  • 이 프로그램의 소스는 GNU AGPL v3 (AGPL-3.0-only)로 공개되어 있습니다. PyMuPDF/MuPDF를 사용합니다.
  • 실행 파일을 재배포할 때는 같은 버전의 소스·빌드 방법과 제3자 고지를 함께 제공해야 합니다.
  • 소스, 빌드 방법, 제3자 라이선스는 GitHub 저장소와 릴리스 페이지에서 확인하세요.
